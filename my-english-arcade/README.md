# MY English Arcade · 문영 영어 놀이터

서울문영여자중학교 교과서의 674개 어휘·예문으로 학습하는 12종 게임입니다.

주소: https://tfellow.github.io/web/my-english-arcade/

## 학생의 학습 흐름

1. 학교 Google 계정으로 로그인합니다. 기존 MY 앱과 로그인을 공유하며 학번은 학교 계정에서 가져옵니다. 별명을 정할 수 있습니다.
2. 교재 학년·단원·문제 수와 게임을 선택합니다.
3. 결과에서 정답률·점수·시간을 확인합니다. 틀린 문항의 뜻·영영풀이·예문·해석을 읽고 바로 복습합니다.
4. ‘나의 기록’에서 게임별 성적과 아직 틀리는 문제를 봅니다. 복습 버튼은 게임·단원별로 묶여 있습니다.
5. 새로운 복습 게임의 첫 답을 맞히면 해당 문항은 복습 목록에서 빠집니다.

학생에게 저장 안내, 재전송, 백업, CSV, 결과 코드, 결과 파일 버튼을 표시하지 않습니다. 기기 저장과 계정별 자동 전송은 내부적으로 유지합니다. 일시적인 전송 실패는 온라인 복귀와 주기적 자동 재시도로 처리합니다. 로그인 학생은 본인 서버 기록과 기기 기록을 합쳐 보고 같은 결과는 중복 집계하지 않습니다. 비로그인 결과는 다른 사람의 계정에 자동 귀속하지 않습니다.

## 교사의 통계

관리자 Google 계정으로 교사실에 들어갑니다. 계정 설정은 [AUTH-HANDOFF.md](AUTH-HANDOFF.md)를 참고하세요.

- 필터: 기간(한국 시간), 학생 소속 학년·반·개인, 게임, 교재 학년·단원, 학번·이름·별명.
- 요약: 학습한 학생, 게임 수, 학습 문항, 첫 정답률, 총 시간·평균 시간, 힌트, 별도 복습, 오답 후 다음 도전에서의 정답.
- 비교 표: 학년별·반별·개인별·게임별·단원별·날짜별.
- 취약 문항: 첫 오답률, 오답/출제 횟수, 틀린 학생, 최근에도 오답인 학생.
- CSV: 필터에 해당하는 학생 요약, 상세 응답, 문항 통계.

학생 소속은 공통 `roster`의 현재 정보를 우선 사용합니다. 명단에 접근할 수 없거나 학생이 없으면 학교 학번 규칙(입학연도 4자리 + 학년 1 + 반 2 + 번호 2)으로 분류합니다. `202610101`은 1학년 1반 1번입니다. 로컬 5자리 학번도 지원합니다. 확인되지 않는 계정은 ‘소속 미확인’에 남습니다. **학생 소속 학년과 학습 교재 학년은 별개입니다.**

선택 범위에 실제 학습 기록이 있는 학생만 집계하며, 전체 재학생 참여율이나 미참여자 수는 추정하지 않습니다. 빈 범위의 정답률은 0%가 아닌 ‘—’입니다.

## 채점과 통계 정의

입력의 대소문자·앞뒤/연속 공백·스마트 따옴표는 정규화합니다. 철자·어순·문장부호는 지정 답과 일치해야 합니다. 첫 정답 100 XP, 힌트 후 첫 정답 70 XP, 첫 오답 0 XP입니다. 첫 오답은 같은 게임 뒤쪽에서 한 번 더 연습하며 이 재응답으로 최초 점수나 정답률을 올리지 않습니다.

첫 정답률은 각 게임 문항의 첫 정답 수를 전체 첫 응답 수로 나눕니다. 세션별 백분율의 단순 평균이 아닙니다. 게임마다 필요한 능력·난도가 다르므로 게임별 통계도 확인하세요. 시간은 쉬는 시간과 다른 화면을 보는 시간도 포함한 경과 시간입니다.

오답 개선은 동일 학생·문항·게임·자료버전의 다른 회차를 비교합니다. 필터 기간 내 오답 후 다른 회차에 재도전한 조합 중 최근 첫 답이 정답인 조합 수를 보여줍니다. 같은 게임의 즉시 재출제 정답은 개선으로 중복 집계하지 않습니다. 다시 틀리면 복습 대상에 돌아옵니다.

## 게임

스펠링 챌린지, 문장 공작소, 단어 짝꿍, 뜻을 찾아라, 영단어 탐정, 영영풀이 퀘스트, 빈칸의 비밀, 메모리 플립, 리스닝 랩, 알파벳 믹서, 트루 오어 폴스, 암호 문장 연구소를 제공합니다.

매칭은 최대 6쌍, 나머지는 5·10·15·20문항 중 선택합니다. 스펠링은 문제 시작·다음 문제·힌트 후 입력칸에 자동 포커스를 줍니다. 듣기는 기기 영어 TTS에 따라 음색·작동 여부가 달라집니다. 빈칸은 표제어가 예문에 같은 형태로 등장하는 경우만 출제합니다. 철자 조립은 3~14자 단일 영단어, 문장 게임은 26단어 이하 예문을 사용합니다. 문장 조립은 지정 원문 기준이며 가능한 모든 어순을 자동 인정하지는 않습니다.

## 자료 교체

원본 엑셀에서 변환한 674개(1학년 318개, 2학년 356개, 각 8단원)를 사용합니다. 엑셀 원본은 수정하지 않았습니다.

교사실의 ‘학습 자료와 로그인 설정’에서 JSON·CSV를 가져오면 현재 브라우저에 적용됩니다. 전체 학생에게 배포하려면 내려받은 `bank.js`로 배포 폴더의 `data/bank.js`를 교체합니다. JSON 원본도 보관하세요.

문항 스키마: `data/schema.json`, 결과 구조: `data/result-schema.json`, CSV 예시: `data/template.csv`. 필수 열은 `id,grade,unit,word,meaning`, 선택 열은 `definition,sentence,translation,acceptedAnswers`입니다. ID는 고유해야 하며 CSV 대체 정답은 `color|colour`처럼 구분합니다.

```json
{"version":1,"title":"1학년 1단원","items":[{"id":"g1-u1-active","grade":1,"unit":"1","word":"active","meaning":"활동적인","definition":"doing things that require movement and energy","sentence":"She is very active and friendly.","translation":"그녀는 매우 활동적이며 친절하다.","acceptedAnswers":[]}]}
```

자료버전이 다른 이전 문항은 성적을 보존하되 현재 자료에서 안전하게 복원되지 않는 경우 복습 출제하지 않습니다.

## 로그인·DB 유지보수

기존 Google Identity Services 및 공통 Supabase 인증 세션을 사용합니다. `config.js`, 실제 DB와 RLS는 이번 통계 개선에서 변경하지 않았습니다. 기존 `myea_sessions.payload`에서 통계를 계산하며 새 DB 표·열은 없습니다. 새 결과의 선택 `studentEmail` 필드는 기존 JSON payload에 추가됩니다. 교사의 공통 `roster` 접근은 읽기 전용입니다.

학생 개인 조회는 현재 인증 UUID의 `user_id` 조건과 기존 서버 RLS를 사용합니다. 로컬 기록은 로그아웃 후에도 기기에 남을 수 있습니다. 이 앱은 복습용 클라이언트 채점이며 고부담 시험용 위변조 방지 시스템은 아닙니다.

**수정 전에는 GitHub 최신 코드와 [인계 문서](AUTH-HANDOFF.md)를 먼저 확인하고 오래된 로컬 파일로 폴더 전체를 덮어쓰지 마세요.** 비밀키·service_role 키를 공개 소스에 넣지 마세요.

## 실행과 검증

`index.html`을 브라우저로 열거나 Python이 있으면 `START-LOCAL.cmd`를 실행합니다. Google 로그인은 HTTP(S)에서 이용합니다.

```text
node --test tests/core.test.cjs tests/analytics.test.cjs
node --check app.js
```

정적 실행 파일은 `index.html`, `styles.css`, `core.js`, `analytics.js`, `app.js`, `config.js`, `data/`입니다. 검증 범위는 [QA.md](QA.md)를 참고하세요.
