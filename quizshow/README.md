# 🎤 문영 예술제 퀴즈쇼

퀴즈반 동아리가 예술제 퀴즈쇼에서 쓰는 웹앱입니다. 추천 작품과 교과서 소설 퀴즈를 전자칠판에서 진행할 수 있습니다.

## ▶️ 바로 실행하기

브라우저에서 아래 주소를 열면 됩니다. 설치나 로그인은 필요 없습니다.

**https://tfellow.github.io/web/quizshow/**

- 시작할 때 1문제당 제한 시간(10초 · 15초 · 20초 · 30초 · 무제한)을 고르고 **전체화면으로 시작하기**를 누르세요.
- 전자칠판에서는 가로 화면, 전체화면으로 쓰는 것을 권장합니다.

## 📱 휴대폰(모바일) 버전

**https://tfellow.github.io/web/quizshow/mobile.html**

- 세로 화면에 맞춰 보기를 한 줄씩 크게 보여 주고, 버튼을 손가락으로 누르기 쉽게 키웠습니다.
- `mobile.html`에는 문제가 들어 있지 않고, 같은 폴더의 `index.html`을 불러와 휴대폰 모양으로만 바꿔 보여 줍니다.
  그래서 **`index.html`의 문제를 고치면 모바일 버전에도 자동으로 반영**됩니다. `mobile.html`은 건드리지 않아도 됩니다.
- 모바일 버전은 인터넷 주소로 열어야 동작합니다. (파일을 더블클릭해서 열 때는 `index.html`을 쓰세요.)
- 학교 앱 메인 페이지(https://tfellow.github.io/web/) 퀴즈쇼 카드에 **PC 버전 / 모바일 버전** 버튼이 함께 있습니다.

## 💻 인터넷 없이 실행하기

`index.html` 파일 하나에 모든 내용이 들어 있어 외부 파일이 필요 없습니다.
파일을 내려받아 더블클릭하면 크롬·엣지·웨일 등 브라우저에서 그대로 실행됩니다.

## ✏️ 문제나 내용을 고칠 때

1. 이 폴더의 `index.html`을 수정한 파일로 바꿉니다.
   (GitHub 웹에서 `quizshow` 폴더 → **Add file → Upload files**로 같은 이름 `index.html`을 올리면 덮어써집니다.)
2. 1~2분 뒤 위 주소를 새로고침하면 반영됩니다.
