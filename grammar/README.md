## 처음 한 번만 하는 설정 (약 3분)

독서 여권 앱이 쓰는 **Supabase 프로젝트와 구글 로그인을 그대로 함께 써요.** 새 프로젝트를 만들거나 구글 OAuth를 다시 설정할 필요가 없어요. MY Grammar의 자료는 `mg_`로 시작하는 별도 테이블에만 저장되니 기존 앱 자료는 그대로예요.

1. [Supabase 대시보드](https://supabase.com/dashboard/project/jkxdhyvnrvsiokbbbjtu)에 tfellow@gmail.com 으로 로그인해요.
2. 왼쪽 메뉴 **SQL Editor** → **New query**.
3. `grammar/supabase/01_schema.sql` 파일 내용을 전부 복사해 붙여 넣고 **Run**. (여러 번 실행해도 안전해요.)
4. 새 쿼리에 `grammar/supabase/02_sample_data.sql` 을 붙여 넣고 **Run**. 4단계 교육과정 129개 소단원과 샘플 119문제가 들어가요.
5. 학교 계정으로 학생 화면에 들어가 확인하고, 교사 화면(admin.html)에 tfellow@gmail.com 또는 tfellow@smy.ms.kr 로 들어가 보세요.

> **이미 예전(G1-01 같은 코드) 단원으로 설치했다면** 01·02 대신 `grammar/supabase/03_curriculum.sql` 하나만 실행하면 돼요. 단원이 새 교육과정으로 바뀌고, 학생 기록 · 스탬프 · 선생님이 추가한 문제는 새 단원으로 옮겨져요. 여러 번 실행해도 안전해요.

## 단원 체계

중1 · 중2 · 중3 · 고등·수능 4단계, 대단원 → 소단원 구조예요. 전체 단원표는 [CURRICULUM.md](CURRICULUM.md)에 있어요.

- 코드: `M1-01-2` = 중1 대단원 1 소단원 2, `H-04-2` = 고등·수능 대단원 4 소단원 2 (M2 = 중2, M3 = 중3)
- 단원 내용(설명 · 예문 · 꿀팁)의 원본은 `js/curriculum.js` 예요. 교사 화면 → 단원 관리에서 바로 고칠 수도 있어요.

> 독서 여권에 올려 둔 학생 명단(`roster` 테이블)이 있으면, 학생이 처음 로그인할 때 실명과 학년·반·번호를 자동으로 가져와요. 없으면 구글 계정 이름을 쓰고, 학생이 학년·반·번호를 직접 입력해요.

## 문제 추가하는 방법 (교사 화면 → ➕ 문제 추가)

- **하나씩**: 단원·유형을 고르고 입력 → 👀 미리보기 → 추가하기. 저장하는 순간 학생 화면에 나와요.
- **한꺼번에**: `양식(TSV) 내려받기` → 구글 시트/엑셀에서 채우기 → 표 전체 복사 → 붙여넣기 → 🔎 확인하기 → 등록하기. 오류가 있는 줄은 이유를 알려 주고 건너뛰어요. 이미 있는 문제(같은 단원·같은 문장)도 건너뛰어요.
- **AI로 만들기 (Gemini · Claude)**: 단원·개수를 고르고 `프롬프트 복사` → Gemini나 Claude에 붙여넣기 (문제집·참고서 사진이나 PDF를 함께 올려도 돼요) → 나온 표를 일괄 등록 칸에 붙여넣기. **등록 전에 정답을 꼭 검토**해 주세요.
- **고치기**: 문제 관리에서 문제를 누르면 수정 · 숨김 · 삭제. 많이 고칠 땐 `전체 내보내기 (TSV)` → 시트에서 수정 → 그대로 일괄 등록 칸에 붙여넣으면 `id` 열 덕분에 수정으로 처리돼요.

### 문제 양식 (열 순서)

| 열 | 설명 |
| --- | --- |
| topic_code | 단원 코드 (예: M1-01-1). 단원 관리에 있는 코드를 써요 |
| qtype | `mc` 객관식 · `ox` O/X · `blank` 빈칸 · `order` 단어 배열 · `error` 틀린 곳 찾기 (한국어 `객관식`, `빈칸` 등도 인식) |
| prompt | 문제. 빈칸은 `___`, 틀린 곳 찾기는 고를 부분을 `[대괄호]`로, 배열은 우리말 뜻 |
| choices | 객관식 보기를 `|` 로 구분 (예: `am|is|are|be`) |
| answer | 정답. 빈칸에 정답이 여러 개면 `is not|isn't`. 배열은 완성 문장. 틀린 곳 찾기는 대괄호 안의 틀린 부분 |
| explanation | 해설 (틀렸을 때 보여요) |
| difficulty | 1 쉬움 · 2 보통 · 3 어려움 |
| source | 출처 (교과서, 문제집 쪽수 등) |

## 들어 있는 기능

**학생**: 학교 구글 계정 로그인 · 닉네임 직접 만들기 · 학년별 문법 단원(개념 · 예문 듣기 · 시험 꿀팁) · 5가지 문제 유형 · 바로 피드백과 해설 · 간격 반복 복습(라이트너 상자 1→3→7→14→30일) · 오답 노트 · 섞어 풀기(인터리빙) · 60초 타임어택 · XP · 레벨 칭호(Seed → Grammar Queen) · 단원 스탬프 북 · 배지 18종 · 콤보 · 연속 학습 🔥 · 하루 목표 · 주간/월간/전체 순위(닉네임만) · 반 대항전(1인당 평균 XP) · 인증서 자동 발급(이미지 저장 · 인쇄) · 태블릿 가로/휴대폰 세로 화면 · 다크 모드.

**교사**: 기간 선택(오늘 · 7일 · 30일 · 학기 · 직접 지정) · 대시보드(활동 학생, 정답률, 날짜별 그래프, 어려운 문제, 단원별 정답률, XP Top 10) · 학생별 통계(실명 + 닉네임, 정렬 · 검색 · CSV) · 학생 상세(단원별 정답률, 최근 풀이, 정보 수정) · 반별 통계 · 문제별 통계(정답률, 가장 많이 나온 오답) · 문제 탑재 현황 · 문제/단원 관리 · 일괄 등록 · AI 프롬프트 · 인증서 모아 인쇄 · 외부 계정 허용 옵션 · 하루 목표 · 학생 공지 · 관리자 추가.

## 보안

- 학생은 정답을 미리 볼 수 없어요. 정답 확인과 XP 계산은 모두 서버(`mg_submit` 함수)에서 해요.
- 학생은 자기 기록만 읽을 수 있고, 순위표에는 닉네임만 나와요. 실명은 관리자만 볼 수 있어요.
- 외부 계정 허용은 교사 화면 → 설정에서 켜고 끌 수 있어요 (기본: 꺼짐).

## 파일 구성

```
grammar/
  index.html        학생 화면
  admin.html        교사 화면
  guide.html        학생용 사용 설명서
  css/style.css
  js/config.js      Supabase · 구글 로그인 설정, 캐릭터 이미지 경로(MASCOT)
  js/core.js        공통 코드 (데이터 연결, 체험 모드, 레벨 · 배지, 인증서)
  js/app.js         학생 화면 코드
  js/admin.js       교사 화면 코드
  js/curriculum.js  4단계 교육과정 단원 · 개념 설명 · 예문 · 꿀팁 (단원의 원본)
  js/sample-data.js 샘플 문제 (체험 모드용, 02_sample_data.sql 의 원본)
  CURRICULUM.md     전체 단원표
  supabase/01_schema.sql      테이블 · 보안 규칙 · 함수
  supabase/02_sample_data.sql 단원 · 샘플 문제 (새로 설치할 때)
  supabase/03_curriculum.sql  예전 단원 → 새 교육과정으로 바꾸기 (이미 설치했을 때)
```

선생님 캐릭터 이미지를 쓰려면 `grammar/img/mascot.png` 로 올리고 `js/config.js` 의 `MASCOT: "img/mascot.png"` 로 바꾸면 돼요.
