## 2. 교사 과제 출제 및 실시간 관리 기능

### ① 학년·반 맞춤형 한국어 제시문 출제 및 수정 (`✏️ 수정` / `🗑️ 삭제`)
- **대상 학년 및 반 지정:** `전학년 공통` 또는 `1·2·3학년`, `전체 반 공통` 또는 `1~4반 전용`(1학년은 1~3반 자동 제한)으로 세분화하여 출제할 수 있습니다.
- **학생 화면 공개 체크박스 (`☑️ 공개`):** 과제를 미리 여러 개 만들어 두고 **체크박스를 켠 과제만 해당 학년·반 학생 화면에 실시간으로 노출**할 수 있습니다.
- **등록된 과제 즉시 수정 (`✏️ 수정`):** 이미 출제한 과제도 삭제 후 다시 만들 필요 없이 **`✏️ 수정`** 버튼을 눌러 제한시간, 채점 기준, 제출 허용 횟수, 복수 모범답안을 언제든 수정할 수 있습니다.

### ② 제한시간 타이머 및 시간초과 자동 강제 발송 (`⏱️ 타이머`)
- 과제별로 `제한시간 없음`, `1분`, `2분`, `3분(권장)`, `5분`, `10분`, `15분`, `20분` 중 선택할 수 있습니다.
- 학생이 제한시간 과제를 선택하면 즉시 카운트다운이 시작되며, **남은 시간이 `00:00`이 되면 학생이 제출 버튼을 누르지 않아도 그때까지 작성한 내용이 자동으로 채점되어 교사 대시보드로 강제 발송**됩니다 (`🚨 시간초과 강제발송` 배지 표시).

### ③ 제출 허용 횟수 제한 (`🔒 기본 1회 제출` ~ `♾️ 무제한`)
- **기본값 (`🔒 1회만 제출 가능`):** 학생이 **`🤖 AI 채점 및 피드백 받기`** 버튼을 한 번 눌러 제출하면 즉시 버튼이 **`🔒 제출 완료 (1/1회 제출 완료 — 추가 제출 불가)`**로 잠기며 입력창이 비활성화됩니다.
- **교사 설정 옵션:** 과제 성격에 따라 교사가 **`1회(기본값)` / `2회` / `3회` / `5회` / `♾️ 무제한 연습 허용`** 중에서 자유롭게 지정할 수 있습니다.

### ④ 복수 모범답안 입력 및 자동 완성 (`✨ 모범답안 자동완성`)
- 교사가 모범 답안을 비워두거나 **`✨ 모범답안 자동완성`** 버튼을 누르면 한국어 제시문과 핵심 목표 문법을 결합해 표준 영어 모범 답안을 자동 생성합니다.
- **복수 정답 구분 (`/` 또는 줄바꿈):**
  - 예: `Taxes pay for the clean air which we need. / Taxes pay for the clean air that we need. / Taxes pay for the clean air we need.`
  - 슬래시(`/`)나 줄바꿈 등으로 여러 개의 정답을 입력해 두면, 학생 답안과 **가장 일치도가 높은 정답 후보를 자동 선택**하여 채점합니다.

## 3. 5대 통합 정밀 채점 엔진 (4대 루브릭 100점 만점)

### 📊 4대 영역 루브릭 배점 구조 (총 100점)
1. **의미·어휘 전달 (40점):** 한국어 제시문의 핵심 의미어(내용어) 반영 비율 + 어순(Bigrams) 일치율 평가
2. **목표 구문 활용 (30점):** 교사가 지정한 핵심 목표 문법/표현 활용 여부 평가 (괄호 보충 설명 자동 분리, 3인칭 단수/과거형 굴절 및 대명사 치환 자동 인정)
3. **영문법·어순 (20점):** 주어-동사 수일치, 관사, 전치사, 철자(오타), 구문 어순 평가
4. **대소문자·문장부호 (10점):** 첫 글자 대문자 시작, 문장 끝 마침표(`.!?`), 단어 간 띄어쓰기 평가

### 🔬 5가지 통합 채점 기술
1. **방법 ① Google Gemini 2.5 Flash AI 하이브리드 정밀 채점 (선택 연동):**
   - 교사 화면 상단 **`🤖 Gemini AI 연동 설정`**에 API 키를 저장하면 클라우드에 동기화되어 전교생 채점 시 2.2초 이내 실시간 AI 정밀 첨삭이 작동합니다.
   - 키를 넣지 않거나 무료 호출 한도 초과 시에도 **0초 지연으로 내장 정밀 엔진으로 자동 전환(Fallback)**됩니다.
2. **방법 ② 교사 채점 엄격도 3단계 모드:**
   - **🔒 엄격 서술형 모드 (`strict`):** 모범답안과 단어·어순·관사·수일치가 100% 일치해야 만점 부여 (서술형 평가 대비용)
   - **⚖️ 표준 정밀 채점 (`standard`, 기본값):** 구문 블록·어순·수일치·관사·철자를 정밀 채점하되 정당한 동의어 표현 일부 허용
   - **🌱 유창성·격려 모드 (`fluency`):** 핵심 의미와 목표 구문이 통하면 사소한 관사·부호 실수 감점을 완화
3. **방법 ③ 구문 블록(Chunk/Slot) 분해 및 철자·어순 진단 (`evaluateChunkSlotAlignment`):**
   - 모범답안을 문장 단위 및 전치사구/절 단위 구간(`1구간`, `2구간`...)으로 분해하여 구간별 **핵심 단어 누락, 어순 뒤바뀜(`money like` vs `like money`), 단복수 오류(`Tax` vs `Taxes`), 관사 누락(`a/the`), 철자 오타(`populer` vs `popular`, `word` vs `world`)**를 정밀 진단합니다.
4. **방법 ④ 모범 답안 1:1 시각적 비교 (`buildWordByWordDiffHtml`):**
   - 학생 원문과 교정된 모범답안을 LCS(최장 공통 부분 수열) 알고리즘으로 단어 1:1 대조하여 **잘못 쓴 단어·철자 오타는 빨간색 취소선**, **누락되거나 교정된 단어는 초록색(`+단어`)**으로 한눈에 비교해 보여줍니다.
5. **방법 ⑤ 외부 영문법 엔진(LanguageTool) 이중 검증 + 중복 감점 방지:**
   - 내장 규칙 엔진과 외부 LanguageTool 문법·철자 검사기를 동시에 돌리면서, 동일한 위치의 오류는 하나로 병합하여 중복 감점을 막고 `correctedText`(학생 문장 교정)에 즉시 반영합니다.

- **학년 / 반 / 명렬표 학생별 / 제출 상태별 필터링:**
  - 특정 학년·반 선택 시 해당 반 명렬표 학생 목록이 드롭다운에 자동 표시되며, **미제출 학생도 `(미제출)` 상태로 한눈에 확인**할 수 있습니다.

- **시각화 차트 & CSV 내보내기:**
  - 학급별 평균 점수 막대 차트 및 CEFR 등급 분포 도넛 차트를 제공합니다.
  - **`📥 현재 필터 결과 엑셀(CSV) 다운로드`** 버튼으로 제출시각, 제출구분, 학번, 학년, 반, 번호, 성명, 제시문, 학생작문, 교정문장, 점수, AI 총평 전체를 한글 깨짐 없는 UTF-8 BOM CSV 파일로 즉시 내려받을 수 있습니다.
