👩‍🎓 학생: 이렇게 풀어요

  1. 학교 구글 계정(@smy.ms.kr)으로 로그인하고, 순위표에 보일 닉네임을 정해요. 실명은 선생님만 볼 수 있어요.
  2. 홈에서 🎲 랜덤 / ✅ 객관식 / ✏️ 단답형 중 하나와 10 / 20 / 30문제 / ∞ 무제한 중 한 판의 길이를 고르고 ▶ START를 눌러요. 8개 분야에서 문제가 골고루 나오고, 위쪽에 "7/20"처럼 몇 번째 문제인지 보여요.
  3. 한 판이 끝나면(또는 그만하기를 누르면) 결과 화면이 나와요. 맞힌 수, 정답률, 점수, 🟩🟥 결과 줄, 이번 판에서 틀린 문제와 정답을 보고 🔁 한 판 더를 할 수 있어요. 점수는 판 길이와 상관없이 문제마다 똑같이 쌓여요.
  4. 객관식은 보기를 누르고(키보드 1~4), 단답형은 정답을 쓰고 제출해요. 띄어쓰기·대소문자는 상관없어요.
  5. 답을 내면 정답과 해설 한 줄이 나와요. 영어 문제는 한국어 뜻도 같이 보여 줘요.
  6. 시간 제한: 객관식 30초, 단답형 45초, 영어 문제는 10초 더. 새로고침해도 문제는 바뀌지 않아요.
기능설명
📅 오늘의 10문제전교생이 같은 10문제를 하루 한 번 풀어요. 끝까지 풀면 +3점, 결과를 🟩🟥 모양으로 복사해 자랑할 수 있어요. 게시판 포스터의 QR을 찍으면 로그인한 뒤 바로 시작돼요.
🌅 아침 보너스선생님이 정한 아침 시간(예: 평일 06:00~08:55) 안에 오늘의 10문제를 끝내면 보너스 점수(기본 +3점)를 더 받아요. 시간은 서버가 한국 시간으로 재요. 지금이 보너스 시간이면 홈 화면에 반짝이는 안내가 떠요.
📱 QR 포스터위쪽 📱 QR 포스터 메뉴에서 게시판 포스터와 같은 QR을 볼 수 있어요. 친구에게 QR 이미지나 주소를 보내 주거나 직접 인쇄할 수 있어요.
📅 나의 10문제 기록📊 내 기록에서 날짜별로 오늘의 10문제 결과(🟩🟥), 정답 수, 점수, 끝낸 시각, 걸린 시간, 🌅 아침 보너스를 볼 수 있어요.
🙈 순위표에서 나 빼기📊 내 기록의 스위치를 켜면 친구들이 보는 순위표에 내 닉네임이 나오지 않아요. 나는 내 순위를 볼 수 있고, 점수와 반 대항전 점수는 그대로 쌓여요. (선생님 화면에는 보여요)
📝 오답 다시 풀기틀린 문제만 다시 나와요. 맞히면 오답 노트에서 빠져요.
✂️ 50:50객관식 오답 2개를 지워요. 하루 3번.
⏭️ 건너뛰기기록 없이 다음 문제로 가요. 하루 3번. (오늘의 10문제에서는 못 써요)
💬 한국어 보기영어 문제의 한국어 뜻을 보여 줘요. 쓰면 영어 보너스 +1점이 없어져요.
👑 왕관 찬스가끔 문제 대신 나와요. 다음 문제 점수가 2배가 돼요. (하루 1번까지)
🏅 분야 배지그 분야 문제 중 몇 개를 정복(한 번이라도 맞힘)했는지에 따라 🥉 브론즈 25% → 🥈 실버 50% → 🥇 골드 75% → 👑 퀸 100%로 올라가요. 배지마다 "23 / 40 정복"과 다음 단계까지 남은 문제 수가 보여요. 새 문제가 늘어나도 한 번 받은 단계는 내려가지 않아요.
📚 문제 은행홈 화면에 지금 풀 수 있는 문제 수(영어·객관식·단답형)와 내가 맞힌 문제 수가 보여요. 분야 배지 아래에는 분야별 문제 수가 보여요.
🔥 연속 도전하루에 1문제 이상 풀면 이어져요.

👑 Brain Queen 등급

8개 분야 배지를 한 세트로 모으면 등급이 올라요. 등급은 순위표 닉네임 옆, 내 기록, 선생님 화면에 보여요.

👩‍🏫 선생님 화면 (위쪽 👩‍🏫 교사)

  • 📤 문제 올리기: 프롬프트 복사 → AI에게 붙여 넣기 → AI가 만든 표를 복사해 붙여 넣거나 엑셀 파일 올리기 → 검사하기 → 올리기.
    • ❌ 고쳐야 함: 분야·정답이 비었거나, 보기가 4개가 아니거나, 같은 보기·같은 문제가 있을 때. 이 줄은 올라가지 않아요.
    • ⚠️ 확인 필요: 정답 보기만 길 때, 영어 문장이 15단어를 넘거나 어려운 단어가 있을 때, 단답형 정답이 길 때, 영어 문제에 한국어 번역이 없을 때.
  • 📚 문제 목록: 분야·형식·언어·묶음으로 찾고, 문제별 정답률을 봐요. 스위치로 끄면 학생에게 나오지 않아요. 묶음째 지울 수도 있어요.
  • 👩‍🎓 학생 기록: 오늘·이번 주·이번 달·전체·기간 선택, 반별로 보고 CSV로 받아요. 반·번호는 학번 5자리(예: 1학년 1반 18번 → 10118)로 한 칸에 보여요. 🌅 아침 칸은 아침 보너스를 받은 날 수예요.
  • 📅 오늘의 10문제: 오늘의 10문제 기록만 따로 봐요. 날짜(오늘·어제·이번 주·기간)와 반을 고르고, 빨리 끝낸 순 · 정답 많은 순 · 학번 순으로 정렬해요. 칸: 학번(5자리), 이름, 결과(🟩🟥), 정답, 점수(10문제에서 얻은 점수, 보너스 포함), 시작, 완주 시각, 걸린 시간, 🌅. 위쪽에 도전·완주·만점 인원, 평균 정답, 평균 걸린 시간, 하루를 고르면 문항별 정답률도 나와요. CSV로 받아 보상에 쓰세요. (시작 시각·점수는 2026-11-12부터 기록돼요)
  • 🖨️ QR 포스터: 게시판에 붙일 오늘의 퀴즈 포스터를 인쇄해요. 여기서 정한 문구와 배경 그림은 학생 📱 QR 포스터 메뉴에도 똑같이 보여요. (아래 설명)
  • ⚙️ 설정: 퀴즈 열기, 🌏 English Day(오늘만 모든 문제를 영어로), 영어 문제 비율, 시간 제한, 학교 밖 계정 허용, 왕관 찬스 확률, 🌅 아침 보너스(켜기·시작/끝 시간·점수 1~5·평일만/매일), 기록 지우기.

🖨️ 오늘의 퀴즈 QR 포스터

포스터의 QR은 항상 같은 주소(오늘의 10문제)로 가고, 문제는 서버가 매일 새로 골라요. 그래서 포스터는 한 번만 인쇄해서 게시판에 붙여 두면 돼요. 코팅하면 오래 써요.

  1. 교사 화면 → 🖨️ QR 포스터에서 용지(A4/A3), 큰 제목, 한 줄 문구, 만든 곳 문구(기본: 퀴즈반에서 만들었어요), 🌅 아침 보너스 안내를 정해요.
  2. 배경 그림을 넣으면 위쪽 글자(MOONYOUNG, 제목)는 흰 상자 대신 흰 테두리 글자로 바뀌어서 그림이 그대로 보여요.
  3. (선택) 📋 배경 그림 프롬프트 복사 → 제미나이·챗지피티 그림 만들기에 붙여 넣기 → 받은 그림을 🖼️ 배경 그림 넣기로 골라요. 분위기(가을·겨울·시험 기간·크리스마스 등)를 바꿔 계절마다 새 포스터를 만들 수 있어요.
  4. 미리보기를 보고 🖨️ 인쇄하기. 인쇄 창에서 배경 그래픽 켜기 · 여백 없음 · 배율 100%.
  • AI 그림에는 글자와 QR을 넣지 않게 프롬프트에 적혀 있어요. AI가 그린 QR은 찍어도 열리지 않기 때문에, QR과 글자는 앱이 직접 그림 위에 올려요.
  • 📥 QR 이미지만 받기: 캔바 같은 다른 도구로 포스터를 만들 때 이 QR 그림을 넣으면 돼요. 🔗 주소 복사로 링크만 받을 수도 있어요.
  • 학생이 처음 찍으면 학교 계정 로그인 → 닉네임 정하기 → 바로 오늘의 10문제. 다음 날부터는 로그인이 기억돼서 찍자마자 시작돼요.
  • 보상: 학생 기록의 10문제 완주 · 🌅 아침 칸, 또는 Teacher Hub 보상 규칙의 "Brain Up 오늘의 10문제 완주"·"Brain Up 아침 보너스"를 Class123 으쓱과 연결하세요.

🤖 제미나이 · 챗지피티로 문제 만들기

  1. 교사 화면 📤에서 분야·개수·학년·영어 비율·단답형 비율·주제를 고르고 📋 프롬프트 복사.
  2. 제미나이나 챗지피티에 붙여 넣으면 13칸 표로 문제를 만들어 줘요.
  3. 표를 통째로 복사해서 📤의 붙여넣기 칸에 넣고 🔍 검사하기. (엑셀로 받았다면 파일을 올려도 돼요)
칸쓰는 법
분야국어·문학, 영어, 수학, 사회·역사, 과학, 예술·체육, 경제·시사, IT·미래기술
형식 / 언어객관식·단답형 / 한국어·영어 (비워 두면 보기·한글 유무로 알아서 정해요)
보기1~4객관식만, 4개 모두. 단답형은 비워요.
정답객관식은 번호(1~4). 단답형은 정답, 다른 표기는 세미콜론으로: 세종대왕; 세종
해설 · 한국어 번역선택. 비워도 돼요. 번역은 영어 문제의 '한국어 보기' 힌트로 쓰여요.
학년 · 난이도선택. 1~3

영어 문제는 아주 쉬운 영어로: CEFR A1~A2, 한 문장 15단어 이하, 문제 2문장 이하, 보기 1~4단어. 프롬프트에 이 규칙이 들어 있고, 올릴 때도 한 번 더 검사해요.

🛠️ 처음 한 번 설정

  1. Supabase 대시보드 → SQL Editor → brainup/supabase_brainup.sql 전체를 붙여 넣고 Run. (독서 여권과 같은 프로젝트예요. 새 기능이 생기면 다시 실행해요 — 🌅 아침 보너스도 이때 켜져요)
  2. 교사 화면에서 문제를 올리면 바로 시작할 수 있어요.
  3. 방학 중 Supabase가 멈추지 않도록 GitHub Actions의 Supabase keep-alive가 매일 아침 한 번 접속해요. (GitHub → Actions 탭에서 확인)

정답은 학생 화면으로 내려가지 않고 서버에서 채점해요. 기록은 학생별·날짜별 합계만 저장해서 무료 용량을 아껴요.
