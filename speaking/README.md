# MY Speaking · 말하기 연습

교과서 대화문을 원어민 목소리(TTS)로 듣고 따라 말하면, 음성 인식 결과를 원래 문장과 **단어 단위로 비교**해 점수를 보여 주는 앱이에요.

- 주소: https://tfellow.github.io/web/speaking/ (체험: `?demo=1`)
- 로그인: 독서 여권과 같은 Supabase + 학교 구글 계정(@smy.ms.kr). 교사(is_admin)는 상단 [👩‍🏫 교사].
- 녹음은 **저장하지 않아요**. 크롬 음성 인식(구글 서버에서 글자로 바꿈)의 결과 글자와 점수만 `sp_attempts`에 저장해요.
- 크롬(PC, 갤럭시 탭)에서 마이크가 돼요. 다른 브라우저는 듣기만 돼요.

## 처음 한 번

Supabase SQL Editor에서 `speaking/supabase_speaking.sql`을 실행해 `sp_sets`(대화문), `sp_attempts`(연습 기록) 표를 만들어요.

## 교사

- [＋ 새 대화문 붙여 넣기]: 한 줄에 `이름: 영어 문장 | 한국어 뜻` (뜻은 선택). 이름 없는 줄은 앞 줄에 이어 붙여요. 미리보기로 확인 후 저장, [공개]해야 학생에게 보여요.
- [결과]: 학생별 연습한 줄 수, 평균 최고점(줄마다 가장 잘한 점수의 평균, 안 한 줄은 0), 말한 횟수, 마지막 연습 + 줄별 평균(어려운 문장 찾기), CSV.

## 학생

- 한 줄씩: 🔊 듣기 → 🎤 따라 말하기 → 초록(맞음)/빨강(빠지거나 다르게 들림) 표시와 점수.
- 역할 연기: 내 역할을 고르면 컴퓨터가 다른 역할을 읽고, 내 차례에 마이크가 저절로 켜져요.
- 전체 듣기, 속도 조절(0.6~1.2), 한국어 뜻 보기.

## 채점 방식과 한계

- I'm = I am 같은 줄임말, 2 = two 같은 숫자, 문장부호와 대소문자는 같게 봐요.
- 점수 = 원래 문장의 단어 중 순서대로 맞게 들린 단어 비율(최장 공통 부분열).
- 발음 채점이 아니라 "알아듣게 말했는가"를 봐요. 인식기가 문맥으로 고쳐 주는 편이라 후하게 나올 수 있고, 시끄러우면 낮게 나와요.
