# 🏫 MY Kahoot (Seoul Moonyoung Girls' Middle School)

**서울문영여자중학교** 수업을 위해 제작된 실시간 스피드 퀴즈 & 학습 통계 웹 애플리케이션입니다.

---

## ✨ 주요 기능 요약

1. **⚡ 0.01초 단위 스피드 점수 & 연속 정답(Streak 🔥) 보너스**
   - 정답을 맞혀도 **더 빨리 누른 학생이 더 높은 점수(최대 1,000점, 2배 찬스 시 2,000점)**를 획득합니다.
   - 연속 정답 시 **2연속(+100점) ~ 5연속 이상(+500점)** 추가 보너스가 부여됩니다.

2. **🔐 `@smy.ms.kr` 도메인 + 사전 등록 학생 명단(화이트리스트) 인증**
   - 교사 페이지의 **[우리 학교 학생 명단]** 탭에 `학년 | 반 | 번호 | 이름 | 이메일(@smy.ms.kr)`을 엑셀로 미리 올려두면, **명단에 등록된 학생만 로그인 가능**합니다.
   - 학생은 자기 학번이나 이름을 따로 입력할 필요 없이 이메일 로그인 즉시 학년·반·번호·이름이 자동 매칭됩니다.

3. **🏆 시상대(Podium) & 1등~10등 우선 공개 (+ 전체 등수 펼치기 버튼)**
   - 퀴즈 종료 시 **1~3위 시상대(포디움)**가 먼저 연출되고, 아래 순위표에는 **기본적으로 1등 ~ 10등까지만** 표시됩니다.
   - 선생님께서 **`[➕ 모든 등수 보기 (11등 이하 전체 펼치기)]`** 버튼을 누르실 때만 전체 순위가 공개됩니다.

4. **📥 엑셀(`.xlsx`) 템플릿 완벽 지원**
   - **퀴즈 템플릿**: `my_kahoot/templates/MY_Kahoot_퀴즈_템플릿.xlsx` (기존에 보유하신 퀴즈앤 양식 `퀴즈 템플릿.xlsx`도 그대로 업로드 가능!)
   - **학생 명단 템플릿**: `my_kahoot/templates/MY_Kahoot_학생명단_템플릿.xlsx`

5. **📊 교사용 종합 통계 대시보드**
   - **오답률 워스트 3 문항** 자동 추출 (수업 중 즉시 피드백용)
   - 문항별 정답률, 평균 응답 속도, 보기(▲◆●■)별 선택 비율 분석
   - 학생별 종합 리포트 및 **원클릭 엑셀(`.xlsx`) 성적표 다운로드**
   - 학급별(반별) 누적 비교 및 학생 개인별 회차 성장 추이
