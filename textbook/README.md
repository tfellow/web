# 영어 교과서 수업실
서울문영여자중학교 영어과 · 1·2학년 16개 단원. 첫 화면: https://tfellow.github.io/web/textbook/

- 단원 → 본문 깊이 읽기 또는 In Context → 모두 공개. 좌우 방향키로 이동하고 Space로 공개 후 다음 장으로 이동합니다. F는 전체 화면입니다.
- 단원·페이지 선택기로 즉시 이동할 수 있습니다. 테마와 마지막 수업 위치는 현재 브라우저에 보관됩니다.
- 폴더 전체를 내려받아 index.html을 열면 인터넷 없이 기본 수업을 진행할 수 있습니다. 오프라인에서는 온라인 교사 수정 사항이 표시되지 않습니다.
- 학년별 기존 통합 앱은 첫 화면 하단의 기존 자료에서 열 수 있습니다.

## 공동 관리
tfellow-web 프로젝트의 SQL Editor에서 setup.sql을 최초 한 번 실행하세요. 기존 앱의 테이블이나 정책은 수정하지 않습니다. 이 단계 전에는 기본 수업만 가능합니다. 관리자 화면은 기존 앱과 같은 Google 클라이언트를 사용하며 Supabase가 ID 토큰을 검증합니다. 로그인 토큰은 페이지 메모리에만 유지됩니다. 공개 읽기와 학교에서 지정한 두 Google 이메일의 쓰기 권한은 새 테이블의 RLS에서 분리합니다. 편집한 설명은 학생 화면에서 공개되는 데이터입니다. 병행 편집 시 마지막으로 저장한 설명이 적용됩니다.

## 단원 확장
data/catalog.js의 학년 배열이 서가와 관리자 단원 목록을 만듭니다. 빈 배열인 학년은 준비 중으로 표시합니다. 3학년 자료가 갖춰지면 3학년 배열에 새 단원의 메타데이터를 추가하고 data/3-1.js처럼 기존 단원 파일 형식으로 등록하세요. 각 자료 파일은 lessonLoaded(학년, 단원, 자료)를 호출합니다. sentences와 context의 요소에는 en, ko, vocab, grammar, meaning이 필요하고 대화는 speaker도 포함합니다. 기존 문장 번호는 공동 편집 키이므로 변경 시 데이터도 함께 이관합니다.
