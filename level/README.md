# MY Level Test (영어 레벨 테스트)

https://tfellow.github.io/web/level/ · 체험: `?demo=1` · 교사 화면: `#/teacher`

학생 1명이 12~15분 동안 **단어 → 문법·어휘 → 읽기** 3단계를 풀면 CEFR(하/중/상), 어휘 크기, Lexile, AR(ATOS)·ZPD, 영역별 강점/보완점, 추천 도서(독서 여권 책)를 보여 줘요.

## 처음 한 번
Supabase → SQL Editor → `supabase_level.sql` 붙여 넣고 Run. (독서 여권과 같은 프로젝트·로그인·`is_admin`·`roster` 사용)

## 알고리즘
1. **어휘 크기** — 빈도 구간 1K~6K, 7~9K에서 5단어씩 + 가짜 단어 10개 예/아니오 체크(Meara X-Lex·LexTALE 방식). 구간별 h' = (h − f)/(1 − f)로 아는 척 보정, 높은 구간 단어 4개는 뜻 확인 → 틀린 만큼 4K 이상 구간을 깎아요. 가짜 단어 체크율 40% 이상이면 '신뢰 낮음'.
2. **문법·어휘 12문항, 읽기 5지문(10문항)** — 3PL IRT CAT. P = 0.2 + 0.8/(1+e^(−1.2(θ−b))). EAP(격자 −4.5~4.5) 추정, 현재 θ에서 정보량이 큰 상위 3문항 중 무작위(노출 분산), 같은 문법 태그 연속 회피. 첫 문항은 어휘 크기에서 얻은 θ로 시작.
3. **찍기 감지** — 문법 1.2초 미만, 지문 첫 문항 (단어 수×0.06초, 최소 3초) 미만, 둘째 문항 1.5초 미만은 추정에서 제외(effort-moderated). 20% 이상이면 '빠른 찍기' 표시.
4. **종합** — 문법+읽기 전체 응답으로 EAP, 어휘 θ를 사전분포 N(θv, 1.1²)로 사용. 영역 점수는 다른 영역 결과를 약한 사전정보(SD 1.0)로 써서 흔들림을 줄여요.
5. **환산** — θ 경계 −2/−1/0/1/2/3 = Pre-A1|A1|A2|B1|B2|C1|C2. Lexile 200/450/700/950/1150/1350L에 맞춘 구간 선형, AR은 Lexile 대응표 보간, ZPD = AR −0.7 ~ +1.0. 어휘 크기 ↔ CEFR은 Milton(2010) 기준(750/1500/2500/3250/3750/4500).
6. **문항 보정** — 교사 화면 🧪: 학생 θ를 고정하고 문항별 b를 최대우도(원래 값 쪽 약한 사전) 재추정. 응답 20개 이상·차이 0.3 이상 문항만 `lt_settings.item_b`에 저장 → 다음 시험부터 반영.

시뮬레이션(가상 학생 700명): 종합 θ RMSE ≈ 0.44, CEFR ±1 단계 안 99.7%.
