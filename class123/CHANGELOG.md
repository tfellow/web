## [v1.8.0] - 2026-11-03 (현재 최신 버전)
### 💬 사용자 프롬프트 및 지시사항
- *"우리반, 뽑기, 뒤집기에서 실수로 카드를 주었을 때 최근 카드 취소 메뉴를 만들었으면 좋겠어. 그리고 리포트, 통계, 이력에서도 취소가 되어야 할 거 같아. 혹시 내가 생각하지 못한 것이 있으면 얘기해 줘"*

### ✨ 구현 및 변경 내용
- **최근 카드 부여 취소 (Undo / 롤백) 시스템 완비**:
  - **상단 바 `[↩️ 취소]` 버튼 신설**: 직전에 부여한 내역이 있을 때 상단에 버튼이 자동 활성화되며 원클릭으로 취소 가능
  - **하단 플로팅 실행 취소 스낵바(Toast)**: 카드 부여 직후 화면 하단에 `[↩️ 취소하기]` 버튼이 포함된 안내 토스트가 6초간 노출
  - **단축키 `Ctrl + Z` (Mac `Cmd + Z`) 지원**: 화면 조작 없이 키보드 단축키로 즉각 취소
  - **전원 일괄 부여(Batch) 통째 롤백**: 여러 명에게 일괄 부여한 경우 1회 취소로 해당 인원 전체가 한 번에 복구
  - **완벽한 점수 & 온도계 연동 복구**: 학생 점수(`visibleEussuk/Meossuk`)뿐만 아니라 학급 전체 점수와 황금알 부화 카운트도 정확히 원상 복구
- **리포트 화면 개별 이력 삭제/취소 기능 연동**:
  - `📊 리포트` 상세 이력 타임라인의 각 행마다 `[🗑️]` 삭제 버튼을 클릭하면, 해당 과거 이력 삭제와 함께 해당 학생 점수 및 학급 온도계 점수까지 정확하게 차감 복구되도록 기능 보강

  - `뽑기(랜덤 뽑기)` 당첨자 개별 카드에 `[🌱 카드선택]` 버튼 추가 (`openGiveCardModalForSingle`)
  - `뽑기` 하단 일괄 버튼 영역에 `[🌱 카드 선택]` 버튼 추가 (`openGiveCardModalWithTargets`)

  - `뒤집기` 상단 툴바에 `[🌱 카드 선택]` 일괄 부여 버튼 추가 (`openGiveCardModalToFlipped`)
- **일괄 버튼 명칭 간결화 & 최적화**:
  - `뽑기` 하단: `⭐ 최근 으쓱`, `🌧️ 최근 머쓱`, `🌱 카드 선택`, `🎲 다시 뽑기` 4종 버튼으로 명칭 축소 및 가독성 대폭 향상
  - `뒤집기` 상단: `🔀 다시 섞기`, `👀 전체 뒤집기`, `⭐ 최근 으쓱`, `🌧️ 최근 머쓱`, `🌱 카드 선택`으로 간결화 및 기능 완비

  - `행운의 뽑기` 상단의 `[⭐ 뒤집힌 학생 모두 으쓱 주기]` / `[🌧️ 뒤집힌 학생 모두 머쓱 주기]` 일괄 부여 버튼도 모달 창 없이 최근 카드로 즉시 부여하도록 통일

3. *"내가 지금까지 작성한 프롬프트와 지시사항, 구현된 기능을 자세하게 정리해 주고, 사용 설명서를 동적인 html 파일로 만들어 줘. 수정을 하게 되면 버전 관리도 해 줘. 내가 너에게 지시를 해서 파일이 수정되면 사용 설명서에도 반영을 해 줘."*

- **원클릭 최근 항목 즉시 부여 (`giveQuickRecentCardToStudent`)**: 학생 카드 하단의 `[⭐ 으쓱]` / `[🌧️ 머쓱]` 버튼 클릭 시 모달 창을 띄우지 않고, 가장 최근에 부여했던 으쓱/머쓱 항목으로 즉시 1장 부여 및 이력 기록
- **상세 리포트 이력 일괄 초기화 (`clearReportHistory`)**: `📊 리포트` 상단 및 하단 상세 이력 박스에 `[🗑️ 상세 이력 전체 초기화]` 버튼 추가 (반 전체 또는 선택한 개별 학생 이력 일괄 초기화 지원)
- **동적 HTML 사용 설명서 (`manual.html`) 및 버전 관리 구축**: 실시간 키워드 검색, 탭 필터링, 미니 체험 시뮬레이터, 프롬프트 아카이브, 버전 히스토리 표를 포함한 동적 설명서 제작 및 웹앱 상단 바 `[📖 사용 설명서]` 버튼 연결
