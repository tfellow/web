- **상단바 관리자 이메일 색상 개선**:
  - 다크 테마 시 어두운 배경에서 거의 보이지 않던 관리자 이메일(`tfellow@...`) 텍스트 색상을 선명한 밝은 화이트그레이(`color: #f8fafc !important;`)로 변경.

### 💬 사용자 프롬프트 및 지시사항
- *"학급 이름 편집 버튼 삭제

  점수 초기화, 명렬 붙여넣기/수정 버튼 삭제
  왼쪽 메뉴에서 카드부여 버튼 삭제"*

### ✨ 수정 및 개선 내용
- **학급 이름 편집 버튼 삭제**:
  - 학급명 우측에 위치하던 `[✏️ 이름편집]` 버튼을 삭제
  - 학급명 직접 클릭(`cursor:pointer`) 또는 상단 헤더의 `[🏫 학급관리]` 버튼으로 편리하게 학급 목록/이름 편집 가능
- **쑥쑥점수 표시방법 위치 이동**:
  - 기존 우측 컨트롤 영역에 분리되어 있던 `쑥쑥점수 표시방법` 드롭다운 셀렉트를 좌측 **`[⭐ 으쓱]`, `[🌧️ 머쓱]` 요약 뱃지 바로 오른쪽**으로 이동
  - 뱃지 스타일(`.score-display-select`)을 적용하여 황금알/으쓱/머쓱 뱃지와 유려한 시각적 일체감 형성
- **점수 초기화 및 명렬 붙여넣기/수정 버튼 삭제**:
  - 학생 화면 우측 컨트롤 바에서 중복되어 있던 `[🔄 점수 초기화]` 및 `[📋 명렬 붙여넣기/수정]` 버튼 삭제
  - 학생 화면 상단 헤더 툴바를 `[☑️ 전체 선택/해제]` 단일 버튼으로 간소화하여 시야 확보 및 공간 최적화 (상단 글로벌 헤더 `[📋 학생관리]` 및 좌측 편의도구 `[🔄 점수초기화]`로 통합 운영)
- **왼쪽 메뉴 카드부여 버튼 삭제**:
  - 좌측 시그니처 도구바 최상단에 있던 `[카드부여]` 버튼을 삭제
  - 학생 화면 내의 직접 부여(개별 카드 상단 퀵버튼, 하단 플로팅 선택 액션바 등) 중심의 자연스러운 조작 환경 구축

  - 클라우드에 실제 8개 반 데이터(`2026-1-1` ~ `2026-테스트`)가 안전하게 보존되어 있으므로, 로컬이 샘플 상태일 때는 타임스탬프와 무관하게 **클라우드의 실제 학급 데이터를 최우선 자동 복원**하도록 데이터 보호 아키텍처 재구축
- **관리자 비밀번호 클라우드 실시간 동기화**:
  - 관리자 비밀번호를 로컬 브라우저뿐만 아니라 **Firebase 클라우드(`adminPassword`)에도 함께 암호화 저장**

1. *"학생 카드 상단에 있는 으쓱과 머쓱이 오른쪽 정렬이 되어 있는 것처럼 보이는데, 하단에 있는 으쓱, 머쓱 버튼처럼 정렬이 되었으면 좋겠어. 학생 카드 하단에 있는 으쓱이나 머쓱을 눌렀을 경우에는 최근 주었던 항목에 대해서 부여해 주고, 쑥쑥카드 부여하기 창을 따로 띄우지 마."*
2. *"상세 리포트 & 통계 메뉴에서 상세 이력도 한 번에 모두 초기화 할 수 있는 기능과 버튼을 만들어 줘."*
3. *"내가 지금까지 작성한 프롬프트와 지시사항, 구현된 기능을 자세하게 정리해 주고, 사용 설명서를 동적인 html 파일로 만들어 줘. 수정을 하게 되면 버전 관리도 해 줘. 내가 너에게 지시를 해서 파일이 수정되면 사용 설명서에도 반영을 해 줘."*

### ✨ 구현 및 변경 내용
- **학생 카드 상단 점수 배지 중앙 정렬**: `.student-card-top` 정렬을 `center`로 변경하여 하단 으쓱/머쓱 버튼과 대칭이 되도록 개선
- **원클릭 최근 항목 즉시 부여 (`giveQuickRecentCardToStudent`)**: 학생 카드 하단의 `[⭐ 으쓱]` / `[🌧️ 머쓱]` 버튼 클릭 시 모달 창을 띄우지 않고, 가장 최근에 부여했던 으쓱/머쓱 항목으로 즉시 1장 부여 및 이력 기록
- **상세 리포트 이력 일괄 초기화 (`clearReportHistory`)**: `📊 리포트` 상단 및 하단 상세 이력 박스에 `[🗑️ 상세 이력 전체 초기화]` 버튼 추가 (반 전체 또는 선택한 개별 학생 이력 일괄 초기화 지원)
- **동적 HTML 사용 설명서 (`manual.html`) 및 버전 관리 구축**: 실시간 키워드 검색, 탭 필터링, 미니 체험 시뮬레이터, 프롬프트 아카이브, 버전 히스토리 표를 포함한 동적 설명서 제작 및 웹앱 상단 바 `[📖 사용 설명서]` 버튼 연결

## [v1.3.0] - 2026-10-27
### 💬 사용자 프롬프트 및 지시사항
- *"으쓱 카드 목록에서 다음을 기본으로 세팅해 줘: 숙제, Kahoot, QuizN, 발표 우수, 오류 발견"*
- *"머쓱 카드 목록에서 다음을 기본으로 세팅해 줘: 지각, 준비물, 수업태도 불량"*
- *"우리반을 눌렀을 때 나오는 학생 개별 칸에 O번 여 라는 것을 없애고 그 아래 칸에 이름 옆에 '번' '여' 이런 말 없애고, 동그란 배경과 함께 그냥 번호의 숫자만 나오게 수정. 별표 다음에는 바로 숫자가 나오고, 구름 다음에는 아래에 숫자가 나오는데 그것도 통일해서 아이콘 다음에 숫자가 나오도록 해 줘."*

### ✨ 구현 및 변경 내용
- **맞춤 기본 카드 세팅**: 으쓱 5종(`숙제`, `Kahoot`, `QuizN`, `발표 우수`, `오류 발견`) 및 머쓱 3종(`지각`, `준비물`, `수업태도 불량`) 기본 적용 (기존 LocalStorage 자동 마이그레이션 포함)
- **학생 개별 카드 UI 개선**: 상단 `O번 여` 배지 제거, 이름 왼쪽에 원형 배경 숫자 배지(`.student-num-circle`) 적용, `⭐`와 `🌧️` 모두 `아이콘 + 숫자` 가로 한 줄(`nowrap`) 표기로 통일
