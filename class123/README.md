## ✨ 2. 주요 핵심 기능

1. **👥 우리반 학생 카드 & 원클릭 최근 카드 부여**
   - 학생 카드 하단의 `[⭐ 으쓱]` / `[🌧️ 머쓱]` 클릭 시 모달 없이 **가장 최근 항목으로 1장 즉시 부여**
   - 깔끔한 원형 번호 배지 + 성별/점수 표시 + 카드 다중 선택 부여 지원
2. **🎲 랜덤 뽑기 & 🍀 행운의 뽑기 (카드 뒤집기)**
   - 1~9명 슬롯머신 랜덤 뽑기 (전원 뽑힐 때까지 자동 중복 방지)
   - 순서 정하기용 카드 셔플 및 뒤집기
   - 뽑힌 화면에서 바로 **원클릭 최근 으쓱/머쓱 부여** (개별 및 전원 일괄)
3. **🥚 학급 온도계 & 황금알 목표 보상**
   - 학급 전체의 으쓱/머쓱 비율을 계산하여 실시간 알 부화 게이지 표시
   - 목표 황금알 달성 시 화려한 골드 축하 애니메이션과 사운드 연출
4. **📚 학급별 진도표 (체크리스트 + 기록장)**
   - 반별 차시 완료 여부 원클릭 체크 + 수업 일자/메모 실시간 기록
5. **📊 상세 리포트 & 통계**
   - 반 전체/개별 학생 통계, 항목별 쑥쑥 랭킹, 상세 부여 이력 타임라인
   - 엑셀(CSV) 3종 다운로드 및 상세 이력 원클릭 일괄 초기화
6. **🏫 학급 순서 변경 & 학급 숨기기**
   - 드래그 앤 드롭 및 화살표로 학급 순서 변경, 방학/종업 학급 숨기기 지원
7. **💾 100% 로컬 저장 & JSON 백업/복원**
   - 브라우저에 자동 저장되며, 언제든 JSON 파일로 안전하게 백업 및 타 기기 복원 가능

## 🚀 3. GitHub Pages로 무료 온라인 웹사이트 배포하는 방법

본 프로젝트는 순수 HTML, CSS, JavaScript로 구성되어 있어 **GitHub Pages를 통해 1분 만에 무료 웹사이트로 배포**할 수 있습니다. 어디서나 태블릿, 스마트폰, 교실 PC의 브라우저에서 URL로 바로 사용 가능합니다.

### 배포 순서:
1. **GitHub에서 새 저장소 생성**:
   - [GitHub.com](https://github.com)에 로그인 후 `New repository` 클릭
   - 저장소 이름(Repository name)에 `Class123-Plus` 입력 (Public 또는 Private)
   - `Create repository` 클릭
2. **현재 폴더의 코드를 GitHub에 푸시**:
   ```bash
   git remote add origin https://github.com/계정아이디/Class123-Plus.git
   git branch -M main
   git push -u origin main
   ```
3. **GitHub Pages 활성화**:
   - 생성한 저장소의 **Settings** → 좌측 **Pages** 메뉴 클릭
   - **Branch** 설정을 `main` / `(root)`로 선택하고 **Save** 클릭
   - 1~2분 뒤 상단에 표시되는 **`https://계정아이디.github.io/Class123-Plus/`** 링크를 통해 어디서나 접속!
