# MY History Museum · 문영 역사 박물관

2022 개정 중학교 역사 교과서(비상교육, 이병인 외) **역사 ①(세계사)·역사 ②(한국사)**를 한 박물관에서 나란히 관람하며 배우는 앱이에요.
첫 화면: https://tfellow.github.io/web/history/

- **로비**: 세계사·한국사 두 줄 연표. 같은 시기의 세계와 우리 역사를 한눈에 봐요.
- **전시관 = 대단원**(세계사관 7개, 한국사관 6개), **전시실 = 중단원**(40곳), **진열장 = 소단원**
- **전시실 코너 5개**
  1. 해설 읽기: 본문, 용어 풀이(한자 뜻), 더 알아보기, 필기 노트 빈칸, 생각 질문, 나란히 보기 링크
  2. 사료·유물: 사료를 읽고 내 답 쓰기 → 예시 답안 비교 (교사가 답을 모아 봐요)
  3. 인물·개념 카드: 뒤집기, 설명 보고 이름 고르기, 간격 반복 복습
  4. 연표·인과: 연표 순서 맞추기, 원인 → 사건 → 결과 잇기, 같은 시기 세계사·한국사 짝 맞추기
  5. 확인 퀴즈: 10문항 서버 채점, 근거 문단 링크
- **관람 도장**: 퀴즈 8점 이상이면 관람 도장, 퀴즈 만점 + 퍼즐 3개 + 사료 답이 있으면 금빛 도장
- 로그인은 독서 여권·지식 여권·Reading Metro와 같아요(Google → Supabase, 같은 profiles·교사 계정·외부 이용자 설정).
- 안내도와 연표는 누구나 볼 수 있고, 교과서 본문·사료·퀴즈는 로그인한 이용자만 받을 수 있어요. 그래서 본문은 저장소에 두지 않고 Supabase(`hm_rooms`)에만 넣어요.

## 처음 한 번
1. Supabase SQL Editor에서 `history/setup.sql` 실행 (기존 테이블·함수는 바꾸지 않아요)
2. 비공개로 만든 `history_seed.sql` 실행 (본문·퀴즈 등록, 여러 번 실행해도 괜찮아요)

## 전시실을 열거나 고칠 때
```
node history/tools/build.mjs <비공개 원본 폴더> <비공개 출력 폴더>
```
- 원본 폴더에 전시실마다 `<id>.json`(해설·용어·사료·카드·연표·인과·나란히 짝·필기 노트)과 `<id>.q.json`(퀴즈 10문항, 정답을 `o`의 맨 앞에)을 둬요.
- `catalog.js`에서 그 전시실에 `open: true`를 넣으면 문이 열려요.
- 빌드가 검사하는 것: 진열장 제목이 안내도와 같은지, 근거 문단, 카드 이름 중복, 퀴즈 10문항·선택지 4개·정답이 가장 길지 않은지. 정답 위치는 1·2·3·4가 고르게 섞여요.
- 출력 폴더에만 생기는 것(비공개): `history_seed.sql`, `history_preview.js`(내 컴퓨터 미리보기용)
- 필기 노트의 `[[낱말]]`은 눌러서 여는 빈칸이 돼요.
